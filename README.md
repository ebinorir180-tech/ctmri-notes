# CT・MRI 救急症例ノート（スマホ用アプリ版）

ホーム画面に追加して使える Web アプリ（PWA）です。HTTPS のサーバーに置くと、スマホにインストールでき、オフラインでも使えます。

## ファイル
- index.html … アプリ本体（すべての症例データを含む）
- manifest.webmanifest … アプリ名・アイコンの設定
- sw.js … オフライン用（ファイルのキャッシュ）
- icons/ … アイコン画像

フォルダの構成を変えずに、そのまま置いてください。

## 公開のしかた（GitHub Pages の例・無料）
1. GitHub でアカウントを作り、新しいリポジトリ（例：ctmri-notes）を作る
2. このフォルダの中身をすべてアップロードする（Add file → Upload files）
3. リポジトリの Settings → Pages で、Branch を main / root にして Save
4. 数分後に表示される https://（ユーザー名）.github.io/ctmri-notes/ が公開アドレス

院内の Web サーバーに置く場合も、HTTPS で配信できる場所であれば同じです。
※ リンクを知っている人は誰でも開けます。施設の方針を確認してから公開してください。

## スマホへのインストール
- iPhone：Safari で公開アドレスを開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chrome で開く → メニュー（︙）→ 「アプリをインストール」または「ホーム画面に追加」

一度開いておくと、以後はネットがなくても使えます。

## 更新するとき
index.html を新しいものに置き換え、sw.js の 1 行目にある VERSION の文字を変えて（例：v0.4.3）アップロードします。利用者がアプリを次に開いたときに新しい内容になります。
